# Harness-инжиниринг при разработке веб-сервисов

Экспериментальные материалы исследования с локальной Qwen3.8-27B, llama.cpp и OpenCode.

## Навигация

| Путь | Назначение |
|---|---|
| `configs/` | конфигурация OpenCode и скрипт llama.cpp |
| `prompts/` | запросы по каждому тесту, с пометками о подтверждённости |
| `sessions/` | полные доступные экспорты OpenCode |
| `results/` | сводки по предварительным тестам, трём попыткам сервиса и APC |
| `baseline-project/` | частичный исходный проект (требуется дополнение) |
| `artifacts/shortener-success/` | место для подлинного результата успешной реализации |
| `apc/` | место для исходников плагина, тестов, логов |
| `reports/` | отчёт технической проверки APC |
| `SECURITY.md` | проверка приватных сведений перед публикацией |

## Последовательность испытаний

1. Анализ текущего Go-проекта и README.
2. Генерация минимального HTTP `/health`.
3. Исправление отсутствующей `sum()`.
4. Сокращатель ссылок: переполнение контекста 16K.
5. Сокращатель ссылок: продолжение с 32K, 49,9 мин без завершения.
6. Сокращатель ссылок: структурированный запрос с 32K, 21,6 мин, успешны `go test` и `go vet`.
7. Дополнительная проверка Race Detector после установки GCC (не выполнена из-за `runtime/cgo`).
8. Проверка APC в режиме observe и сравнительный эксперимент с активным контроллером.
