# Конфигурация экспериментального стенда

Этот каталог содержит конфигурации, использованные для документирования экспериментов по harness-инжинирингу при разработке веб-сервиса на Go.

> **Важно:** файлы восстановлены по зафиксированным параметрам экспериментов и не являются побайтовыми копиями исходных файлов с исследовательского компьютера. Перед публикацией и воспроизведением необходимо сверить их с оригиналами.

## Состав каталога

- **`opencode.json`** — конфигурация OpenCode для подключения локального сервера llama.cpp через интерфейс, совместимый с OpenAI API.
- **`start-llama.ps1`** — PowerShell-скрипт запуска `llama-server` с параметрами инференса.

## Экспериментальная конфигурация

| Параметр | Значение |
| --- | --- |
| Модель | Qwen3.8-27B, GGUF |
| Квантование весов | Q3_K_M |
| Сервер инференса | llama.cpp (`llama-server`) |
| Агентная среда | OpenCode Desktop 2.2.0 |
| Видеокарта | NVIDIA RTX 5070 Ti, 16 ГБ VRAM |
| Адрес локального API | `http://127.0.0.1:8080/v1` |
| Алиас модели | `qwen38-local` |
| Контекстное окно | 32 768 токенов |
| Максимальный вывод, заданный в OpenCode | 8 192 токена |
| Flash Attention | Включён |
| KV-кеш (K/V) | `q8_0` / `q8_0` |
| Слои на GPU | `auto` |
| Параллельность сервера | `1` |
| Шаблоны чата | `--jinja` |
| Вариант рассуждений в OpenCode | `default` |

На раннем этапе применялось контекстное окно **16 384 токена**. Представленные конфигурации соответствуют последующим экспериментам с окном **32 768 токенов**. Отдельный лимит токенов рассуждений в скрипте не устанавливается. Параметры сэмплирования, включая `temperature`, не подтверждены по исходным конфигурационным файлам.

## Запуск сервера модели

1. Установить совместимую сборку llama.cpp с CUDA и подготовить файл модели `.gguf`.
2. Проверить путь к исполняемому файлу `llama-server.exe` внутри `start-llama.ps1` (в реконструкции указан `C:\llama-cuda\llama-server.exe`).
3. В PowerShell указать **реальный** абсолютный путь к модели и запустить скрипт:

```powershell
$env:QWEN_GGUF_PATH = 'D:\models\model-Q3_K_M.gguf'
.\start-llama.ps1
```

Путь в примере условный: он не является установленным фактическим расположением модели в эксперименте.

## Подключение OpenCode

Скопировать или объединить содержимое `opencode.json` с пользовательской конфигурацией OpenCode. Во время экспериментов расположение файла было следующим:

```text
C:\Users\RemoteAccess\.config\opencode\opencode.json
```

Убедиться, что локальный сервер запущен на `127.0.0.1:8080`, а алиас модели в llama.cpp соответствует полю `id` в конфигурации OpenCode. В OpenCode выбрать модель `local/qwen38`.

## Примечания о воспроизводимости

- OpenCode управляет историей диалога, вызовами инструментов и передачей результатов обратно модели; llama.cpp выполняет локальный инференс.
- Наличие совместимого с OpenAI API **не означает** обращения к облачным сервисам OpenAI.
- Для точного воспроизведения необходимо дополнительно фиксировать версии llama.cpp, модели, драйвера CUDA, Go и содержимое исходного проекта.
- Испытание с `go test -race` зависит также от корректно установленного и доступного C-компилятора; его состояние не задаётся этими двумя конфигурационными файлами.
