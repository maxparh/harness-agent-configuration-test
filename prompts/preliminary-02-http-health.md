# Предварительное испытание: HTTP /health

Создай в текущем проекте простой HTTP-сервер на Go.

Требования:
- GET /health возвращает JSON {"status":"ok"}.
- Используй только стандартную библиотеку Go.
- Добавь main.go и go.mod.
- Создай unit-тест для /health.
- Запусти go test ./... и исправь ошибки, если они возникнут.

В конце сообщи, какие файлы созданы, результат тестов и фактически выполненные команды.
