# Предварительное испытание: анализ проекта

Изучи текущий проект с помощью доступных инструментов. Получи список файлов проекта, прочитай README.md, определи используемый стек и назначение проекта, проверь наличие main.go. Не изменяй файлы и не придумывай содержимое файлов, которые не удалось прочитать.
