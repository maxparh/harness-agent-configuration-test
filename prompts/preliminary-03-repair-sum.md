# Предварительное испытание: исправление отсутствующей sum()

В текущем Go-проекте есть ошибка, из-за которой не проходят тесты.

Твоя задача:
1. Изучи файлы проекта и запусти `go test ./...`.
2. Определи причину ошибки.
3. Исправь проблему, внеся минимально необходимые изменения в исходный код.
4. Не удаляй и не изменяй существующие тесты, чтобы добиться их прохождения.
5. Повторно запусти `go test ./...` и убедись, что все тесты проходят.

Используй только стандартную библиотеку Go.

Работай самостоятельно. В конце кратко объясни, в чём заключалась ошибка, какие изменения были внесены и каков результат тестирования.
