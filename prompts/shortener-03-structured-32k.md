# Промпт: структурированный запуск, 32K (дословный экспорт)

Твоя задача — реализовать HTTP-сервис сокращения ссылок на Go в существующем проекте.

Требования:
- POST /api/links — создание сокращённой ссылки.
- GET /{code} — перенаправление на исходный URL.
- GET /api/links/{code}/stats — статистика переходов.
- Потокобезопасное in-memory хранилище.
- Сохранение работоспособности /health и существующих тестов.
- Использование только стандартной библиотеки Go.
- Не изменять README.md и не удалять существующие тесты.

Работай строго по этапам:

1. Изучи существующие файлы. Кратко перечисли необходимые изменения. Не составляй развёрнутый план.
2. Сразу переходи к созданию файлов и реализации минимальной работоспособной версии.
3. После реализации запускай go test -race ./... и go vet ./....
4. Исправляй обнаруженные ошибки и повторяй проверки.
5. Заверши работу, указав изменённые файлы и фактические результаты тестирования.

Ограничения агентного процесса:
- Не повторяй уже выполненный анализ без объективной необходимости.
- Не переписывай один и тот же план.
- После анализа обязательно переходи к действиям с файлами.
- При возникновении ошибки инструмента попробуй исправить её и продолжить выполнение.
- Если дальнейшее выполнение невозможно, сообщи конкретную причину вместо бесконечного планирования.

Go установлен по пути C:\Program Files\Go\bin\go.exe. При необходимости используй этот путь напрямую.

Работай автономно.
