# Конфигурация стенда

Содержит ранее подготовленные `opencode.json` и `start.ps1`. Путь к GGUF задаётся через `QWEN_GGUF_PATH`.

Контекстное окно основной серии: 32K, первый неудачный запуск: 16K. CUDA выбрана вместо Vulkan после предварительного замера, показавшего ориентировочно пятикратную разницу скорости. Сырые показатели обоих бэкендов здесь отсутствуют, поэтому этот результат считать предварительным.
