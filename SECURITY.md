# Проверка перед публикацией

Экспорты сессий OpenCode могут содержать локальные пути, имена пользователей Windows, случайно прочитанные файлы, команды, текст результатов и другие сведения.

**Перед публичным git push просмотрите `sessions/*.json`, `reports/*` и настройки** на наличие паролей, токенов, персональных данных и приватных путей. Автоматическая фильтрация намеренно не выполнялась, чтобы сохранить научные первичные данные без скрытого изменения. При необходимости сделайте отдельную обезличенную копию с документированными заменами. Не коммитьте GGUF, служебные кэши и секреты.
