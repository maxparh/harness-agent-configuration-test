# Дополнительное тестирование `go test -race`

После успешного создания основных функций была предпринята попытка запустить Go Race Detector. Изначально не был доступен компилятор C; затем пользователь установил GCC 16.2.0 через MSYS2 UCRT64, после чего агент повторил попытку.

Запуск завершился ошибками компиляции `runtime/cgo`. Проверка `-race` не была выполнена; это **не является доказательством гонок данных**. Диагностика составила дополнительную, отдельно учитываемую сессию (около 24,2 мин; дополнительные 38 740 выходных токенов).

См. экспорт `../sessions/shortener-04-structured-plus-race-retry.json`. Файл включает исходную успешную сессию и дополнительное продолжение, поэтому **нельзя складывать содержащиеся в обоих экспортах суммарные токены**, не вычитая исходную часть.
