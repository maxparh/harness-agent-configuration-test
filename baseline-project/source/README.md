# Agent Test

Тестовый проект для проверки локального ИИ-агента на базе Qwen3.8-27B, llama.cpp и OpenCode.

## Назначение

Демонстрационный сервис сокращения ссылок с аналитикой. На первом этапе используется только тестовое описание: реализация ещё не создана.

## Технологии

- Go — серверная часть
- PostgreSQL — планируемое хранилище данных
- Docker — контейнеризация

## Структура проекта

Планируемый основной файл — `main.go`. На момент создания этого README он ещё не добавлен.

## Задание для агента

Изучи текущий проект с помощью доступных инструментов:

1. Получи список файлов проекта.
2. Прочитай `README.md`.
3. Определи используемый стек и назначение проекта.
4. Проверь, существует ли `main.go`.

Не изменяй файлы и не придумывай содержимое файлов, которые не удалось прочитать.
